TP 1: Karakteristik RGB berbasis Cahaya vs CMYK berbasis Tinta

RGB

Red, Green, Blue (Additive/Cahaya)

RGB(0, 0, 0)
RED 0
GREEN 0
BLUE 0
💡 Menggabungkan ketiganya secara maksimal (255) menghasilkan warna PUTIH. Digunakan untuk monitor/layar.

CMYK

Cyan, Magenta, Yellow, Key (Subtractive/Tinta)

CMYK(0, 0, 0, 0)
CYAN 0%
MAGENTA 0%
YELLOW 0%
KEY (BLACK) 0%
💡 Menggabungkan C,M,Y (100%) teoritisnya hitam, tapi prakteknya coklat kotor. Karenanya butuh tinta K (Hitam).
